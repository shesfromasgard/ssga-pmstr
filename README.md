# ssga-pmstr

Este repositório apresenta o código-fonte e as instâncias usadas no artigo "Escalonamento em Máquinas Paralelas Idênticas com Reentrada e Restrições de Ferramentas: Uma Abordagem Evolutiva" submetido no LVIII Simpósio Brasileiro de Pesquisa Operacional em 2026.

Para compilar, utilize o comando "make" (certifique-se de o pacote build-essential instalado em sua máquina). Em seguida, para executar utilize o comando:

```cpp
  ./run {pasta_com_suas_instancias} {número_de_execuçôes_independentes_por_instância}
```
