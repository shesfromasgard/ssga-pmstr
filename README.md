# ssga-pmstr

Este repositório apresenta o código-fonte e as instâncias usadas no artigo "Escalonamento em Máquinas Paralelas Idênticas com Reentrada e Restrições de Ferramentas: Uma Abordagem Evolutiva" submetido no LVIII Simpósio Brasileiro de Pesquisa Operacional em 2026.

Para compilar, utilize o comando "make" (certifique-se que o pacote build-essential está instalado em sua máquina). Em seguida, para executar, utilize o comando:

```cpp
  nohup ./run {pasta_com_suas_instancias} {número_de_execuçôes_independentes_por_instância} &
```

Qualquer dúvida ou pergunta podem ser enviados para o e-mail [anaclpereirasouza@gmail.com](mailto:anaclpereirasouza@gmail.com).

Observação: este código funciona somente em distribuições Linux e é originalmente compilado com gcc14.
